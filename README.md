# Personal Academic Website

A clean, responsive personal academic website inspired by [Emily Wall's academic website](https://emilywall.github.io/index.html).

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | About me, recent news, selected publications, teaching, contact |
| News | `news.html` | Full news timeline |
| Publications | `publications.html` | Complete publication list organized by year |
| Projects | `projects.html` | Research project showcase |
| Teaching | `teaching.html` | Course history with semester links |
| Contact | `contact.html` | Contact information and prospective student guidance |

## Customization

To personalize this website, replace the following placeholder content:

1. **Name**: Replace all instances of `Your Name` with your actual name
2. **Institution**: Update university name, department, and links
3. **Profile photo**: Place your photo at `images/profile.jpg`
4. **Email**: Replace `yourname@university.edu`
5. **Social links**: Update Twitter, Google Scholar, LinkedIn, GitHub URLs
6. **Publications**: Replace placeholder papers with your actual publications
7. **News**: Update with your real news items
8. **Teaching**: Replace with your actual courses

## Deployment (GitHub Pages)

1. Create a new GitHub repository named `yourusername.github.io`
2. Push all files to the `main` branch
3. Go to **Settings → Pages** and set source to `main` branch
4. Your site will be live at `https://yourusername.github.io`

## Tech Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript
- [Font Awesome 6](https://fontawesome.com/) for icons
- [Google Fonts](https://fonts.google.com/) (Lato + Merriweather)
- No build tools required — deploy directly to GitHub Pages
